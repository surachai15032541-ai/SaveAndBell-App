# 🔔 Save and Bell (แอปเช็คของก่อนออกจากบ้าน)

แอปพลิเคชันสำหรับช่วยเตือนความจำและตรวจสอบสิ่งของจำเป็นก่อนออกจากบ้าน ออกแบบในโทนสีน้ำตาลอุ่นสบายตา พัฒนาด้วย **React Native (Expo) + TypeScript**

## ✨ ฟีเจอร์หลักของระบบ
* **ระบบสมาชิก:** สมัครสมาชิกและเข้าสู่ระบบด้วย Username และ Password
* **บันทึกของเข้า-ออก:** เพิ่มรายการสิ่งของพร้อมบันทึกเวลาอัตโนมัติ และลบสิ่งของที่ไม่ใช้งานแล้วออกได้
* **เช็กของใช้จำเป็น:** แสดงรายการของใช้ประจำวัน พร้อมระบบนับความพร้อมก่อนออกเดินทาง
* **Reset เช้าวันใหม่:** ล้างสถานะการเช็กของทั้งหมดในปุ่มเดียวเพื่อเริ่มวันใหม่
* **แจ้งเตือนล่วงหน้า & สถานที่:** ตั้งเวลาแจ้งเตือน เปิด/ปิดสถานะ และบันทึกจุดหมายปลายทาง
* **ประวัติการใช้งาน (Activity Logs):** บันทึกทุกความเคลื่อนไหวในระบบย้อนหลัง

## 🛠️ วิธีติดตั้งและรันโปรเจกต์ (สำหรับนักพัฒนา)
1. ดาวน์โหลดโค้ดโปรเจกต์: `git clone https://github.com/surachai15032541-ai/SaveAndBell-App.git`
2. ติดตั้งแพ็กเกจ: `npm install`
3. เริ่มรันแอปผ่าน Expo Go: `npx expo start`
